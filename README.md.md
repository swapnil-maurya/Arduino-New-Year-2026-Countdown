# Arduino New Year 2026 Countdown & Celebration Project

This project demonstrates a 10-second countdown using Arduino UNO.
It displays countdown numbers on an SSD1306 OLED, controls a Common Anode RGB LED,
and triggers buzzer alerts on every second.

## Features
- 10 to 0 countdown display
- RGB LED color change for each second
- Buzzer sound alerts
- New Year 2026 celebration screen
- Push button start & reset

## Components Used
- Arduino UNO
- SSD1306 OLED Display (I2C)
- Common Anode RGB LED
- Buzzer
- Push Button
- Resistors & Jumper Wires

## Libraries Required
- Adafruit_GFX
- Adafruit_SSD1306
